# Issue templates

Minimal, useful templates that make work capture consistent without being overbearing.
Full field-by-field references land with **GRI-72**.

| Template | Use for |
| -------- | ------- |
| **Action** | Generic catch-all — what · why · when it's done |
| **Feature** | New capability — what · why · acceptance criteria |
| **Problem** | Bug / incident / vulnerability (labelled) — what's wrong · impact · fix |
| **Spike** | Time-boxed investigation — question · timebox · outcome |

See [Issues](../concepts/issues.md) for how templates, states and labels fit together.
