# Issues

Issues are the concrete units of work under a project, owned by a team. Templates are
**minimal, engaging and useful** — never overbearing.

## Templates

| Template | Use for | Captures |
| -------- | ------- | -------- |
| **Action** | The generic catch-all (like most tickets) | What · why · when it's done |
| **Feature** | New capability | What · why · acceptance criteria |
| **Problem** | Bug / incident / vulnerability (labelled) | What's wrong · impact · resolution |
| **Spike** | Time-boxed investigation | Question · timebox · outcome |

## Conventions

- **The issue is the prompt.** Write it so an agent can act on it; store agent plans
  against the issue.
- **Consistent, minimal, measurable states** — see [States](states.md).
- **Useful labels** — see [Labels](labels.md).
- **Agreed [SLAs](slas.md)** where they add value.
