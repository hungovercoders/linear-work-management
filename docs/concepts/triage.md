# Triage

Triage makes **unplanned work** — the things arriving outside the plan — visible and
managed rather than lost. Incoming items land in triage, get assessed, and are routed to
the right project/team with the right template and labels.

    Triage should be worked from a saved view (build to match if it does not exist yet):
