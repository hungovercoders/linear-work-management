# Dashboards

Simple dashboards and saved views make adherence to the operating model observable —
initiatives, projects, triage and SLA health at a glance.

Views are documented **declaratively** with their expected `happydevs` URLs. Where a view
does not exist yet, build it to match the guidance.

| View | Expected URL |
| ---- | ------------ |
| All projects | `linear.app/happydevs/projects/all` |
| Initiatives | `linear.app/happydevs/initiatives` |
| Triage | `linear.app/happydevs/team/GRI/triage` |
