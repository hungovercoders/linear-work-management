# Communication

Comms should be **easy, consistent, manageable and aimed at the right audience**, on a
regular cadence so people stay in the know.

## Channels

| Level | Channel | Audience |
| ----- | ------- | -------- |
| Initiative / strategic | [`#initiative-updates`](https://hungovercoders.slack.com/archives/C0BPS0WL7Q8) | Leadership & stakeholders |
| Project / delivery | [`#project-updates`](https://hungovercoders.slack.com/archives/C0BNXKP69NE) | Delivery teams & interested parties |

Strategic updates roll up initiative progress; delivery updates cover project movement,
milestones and blockers.

!!! tip "Related skill: `linear-status-update`"
    Generate a standard initiative or project update from live Linear data, formatted for
    the right channel. See [skills](../skills/index.md).
