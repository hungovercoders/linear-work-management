# Integrations

Linear connects to where work and communication actually happen.

- **Slack** — initiative and project updates flow to
  [`#initiative-updates`](https://hungovercoders.slack.com/archives/C0BPS0WL7Q8) and
  [`#project-updates`](https://hungovercoders.slack.com/archives/C0BNXKP69NE);
  notification conventions keep noise low.
- **GitHub** — branches and PRs link to issues (Linear provides a branch name per issue);
  PR state drives issue state automation.
